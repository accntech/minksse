# Framework logos

SVG paths are from [Simple Icons](https://simpleicons.org/), retrieved through the Iconify API on 2026-11-01:

- `react.svg`: https://api.iconify.design/simple-icons/react.svg
- `vue.svg`: https://api.iconify.design/simple-icons/vuedotjs.svg
- `svelte.svg`: https://api.iconify.design/simple-icons/svelte.svg

Path geometry is unchanged; each monochrome icon uses its brand color as an explicit fill so it remains visible when embedded as an image.
